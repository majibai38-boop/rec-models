# 整体调用与类型比较

Excel 页签顺序为：类型对比、整体对比、覆盖率诊断、调用明细、耗时分布。Web 使用相同顺序，默认打开类型对比；使用相同的视图与分组标识。

## 比较口径

类型表保持原来的 kernel 分配与 Direct/Comparable/Accounted 覆盖率；整体视图是同一批工作的另一种观察方式，不向主计算或辅助类型重复分配 GPU 时间。TOTAL 继续独立按事件去重，包含未映射 GPU 计算及内存活动，不把任何整体行再相加。

- 整体可比比值 = 可比较完整调用的 GPU 时间之和 / 对应 NPU 时间之和。不是单次比值的平均值。
- Total Time 比值：仅在两端同名逻辑调用的全量范围、单一实现组合可确定时生成；包括未配对调用，不代表工作量已证明等价。其他情况显示空值。不能以配对成功的调用替代全量分母。
- 完整调用时间包括其 scope 内的准备工作和 GPU 内存活动，不包括 CPU runtime 耗时；事件时长之和不是墙钟时间。
- 不同 NPU/GPU 实现组合分组，跨组可能有父子调用重叠。组内同一事件不重复纳入比值，重叠调用 ID 在明细中可见。整体页没有直接求和的 TOTAL。
- 通用完整调用要求唯一可信 CPU 匹配、兼容的完整输入元数据、可靠 kernel owner 和完整 NPU detail 范围才标为可比较。缺失 TensorList 元素 shape 记为“不完整”，不是实际冲突，也不是自动匹配通配符。已存在的 CPU bundle/FA 规则仍展示其原始匹配依据。

## 导航与文件

- `whole_call_statistic.csv`：按完整调用及两端实现组合聚合，包含可比/待核实调用数、两列比值、全量范围说明。
- `whole_call_mapping.csv`：逐调用证据，包括 CPU 索引、kernel/内存活动独立索引、完整名称、耗时、关联依据、问题与重叠记录。
- 类型表新增整体比较状态和关联整体调用。Excel 点击关联名称进入调用明细；Web 按 Device/Type/Core 精确过滤关联分组，再进入逐调用列表。
- Excel 默认折叠详细编号、完整名称、总体调用数等列，展开后可审计。保留类型表既有融合分组样式。
- Div/Sub 专项精度路径不放回整体表格；类型行只提供排查报告入口。

没有独立可比较工作时，展示层性能比留空，不以 0 暗示 GPU 免费完成。底层类型 CSV 的原始记账值不因新视图而改变。颜色延用 >=2 深绿、[1,2) 浅绿、<1 黄色。

新视图须重新运行比较生成；旧结果与输入不会被自动覆写。运行时校验会核对整体行的事件索引、时间、可比比值、分组去重及总体比值分子分母。
