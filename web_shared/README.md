# 共享工作台主题

`theme.css` 是 Profiling Workbench 与 Workload Modeler 的共同样式入口，包含设计变量、侧栏/主内容布局、字体、按钮、输入框、页签、结果卡片、表格及性能比颜色。

- Profiling：在 `profiling_web/frontend/src/main.js` 中直接导入，由 Vite 打包；修改后重新执行前端 build。Docker 构建也会复制本目录。
- Workload：通过只读的 `/static/theme.css` 返回同一源文件，无需 Node 构建。部署时需保留仓库的 `web_shared/` 目录；首次升级需重启服务以加载路由，后续仅改 CSS 可刷新页面。
- 两边特有的组件布局分别留在自身 CSS 中，不在共享文件中加入数据处理或业务规则。

主题以 profiling 的浅灰背景、白色卡片和青绿色强调色为基准。桌面侧栏宽 242px，1100px 以下缩至 205px，760px 以下改为上下布局。性能比颜色统一为 `>=2` 深绿色、`>=1且<2` 浅绿色、`<1` 黄色；各工具的比值方向仍由各自标签说明，不能把 GPU/NPU 比值与预测的源/目标比值混为同一口径。

维护时优先修改 `--ui-*` 变量或共享组件。检查两边的输入页、历史结果、表格、弹窗，以及窄屏横向溢出；不要修改分析算法来配合样式。
